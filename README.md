# react-quiz

Простая викторина на React + Vite + TypeScript с вопросами о React.

## Что реализовано

- Викторина с несколькими вопросами о React
- Прогресс-бар, показывающий текущий шаг
- Подсчёт правильных ответов
- Страница результатов с итоговым счётом
- Возможность начать викторину заново

## Стек

- React 19
- TypeScript 6
- Vite
- Sass
- ESLint

## Структура проекта

- `src/` — исходный код приложения
  - `components/` — компоненты викторины
    - `Quiz/` — основной компонент викторины
    - `Game.tsx` — компонент игры с вопросами
    - `Result.tsx` — компонент результатов
    - `Questions.tsx` — данные вопросов
  - `App.tsx` — главный компонент приложения
- `public/` — статические файлы
